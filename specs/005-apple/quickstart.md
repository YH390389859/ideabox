# Quickstart: Apple 风格底部导航栏验证

**Feature**: 005-apple  
**Date**: 2025-10-02  
**目标**: 快速验证导航栏在真实场景下的表现和合规性

---

## 前置条件

### 开发环境
- ✅ Xcode 14.0 或更高版本
- ✅ iOS 15.0+ 模拟器或真机
- ✅ 已编译的 IdeaBox 应用（debug 模式）

- 📱 iPhone 12 或更新机型（真机测试触觉反馈）

## 第 1 部分：视觉验证 (3 分钟)

### 1.1 基础外观 ✅

**步骤**:
1. 启动应用
2. 观察底部导航栏

**验证清单**:
- [ ] 导航栏使用毛玻璃背景（内容可透过）
- [ ] "今天"按钮使用 `calendar.badge.clock` 图标
- [ ] "添加"按钮使用 `plus.circle.fill` 图标
- [ ] "个人中心"使用 `person.crop.circle.fill` 图标
- [ ] 按钮尺寸视觉上一致（约 44x44pt）
- [ ] 间距均匀，布局对称

**预期效果**:
```
[今天]                    [+] [👤]
左侧独立按钮              右侧按钮组
```

### 1.2 深色模式 ✅

**步骤**:
1. 下拉控制中心
2. 切换外观模式（浅色 ↔ 深色）
3. 观察导航栏变化

**验证清单**:
- [ ] 背景自动调整为深色毛玻璃
- [ ] 图标颜色适配深色主题（更亮的蓝色）
- [ ] 文本清晰可见，对比度足够
- [ ] 无需重启应用即可切换

**对比截图**:
- 浅色模式：白色/浅灰背景，标准蓝色图标
- 深色模式：深灰/黑色背景，亮蓝色图标

### 1.3 布局一致性 ⭐

**步骤**:
1. 切换不同页面/标签
2. 验证导航栏在各页面的表现

**验证清单**:
- [ ] 导航栏位置固定在底部
- [ ] 高度和间距保持一致
- [ ] 切换页面时无闪烁或重布局

## 第 4 部分：辅助功能验证 (4 分钟)

### 4.1 VoiceOver 测试 ✅

**步骤**:
1. 设置 > 辅助功能 > VoiceOver > 开启
2. 滑动到导航栏区域
3. 依次聚焦每个按钮

**验证清单**:
- [ ] 所有按钮可被 VoiceOver 识别
- [ ] "今天"按钮读出"今天按钮，轻点两下跳转到今天"
- [ ] "添加"按钮读出"添加按钮，轻点两下创建新事项"
- [ ] "个人中心"读出"个人中心按钮"
- [ ] 焦点顺序合理（从左到右）
- [ ] 双击可正确触发操作

**提示**: 三指三次点击快速开关 VoiceOver

### 4.2 动态字体测试 ✅

**步骤**:
1. 设置 > 辅助功能 > 显示与文字大小 > 更大字体
2. 拖动滑块到最大
3. 返回应用查看导航栏
4. 拖动滑块到最小
5. 再次查看导航栏

**验证清单**:
- [ ] 最大字体时，文本和图标按比例放大
- [ ] 按钮布局不破坏，无截断

- [ ] 最小字体时，布局紧凑但清晰

**字体大小范围**:
- XS: 所有内容可见
- M: 标准布局
- XXXL: 适配大字体
- 辅助功能尺寸: 可能需要紧凑布局

### 4.3 减少动画测试 ✅

**步骤**:
1. 设置 > 辅助功能 > 动态效果 > 减少动态效果 > 开启
2. 返回应用
3. 切换日期，观察"今天"按钮

- [ ] 动画时长 < 0.15 秒（或无动画）
- [ ] 核心功能不受影响

## 常见问题排查

### 问题 1: 毛玻璃效果不明显

**原因**: 背景内容颜色单一
**解决**: 添加多种颜色的内容验证效果

### 问题 2: 真机无触觉反馈

**检查**:
1. 设备是否支持 Taptic Engine（iPhone 7+）
2. 设置 > 声音与触感 > 系统触感反馈 是否开启
3. 静音开关是否打开（可能影响）

### 问题 3: VoiceOver 读不出按钮

**检查**:
1. 是否设置了 `.accessibilityLabel()`
2. 按钮是否被隐藏（`isVisible = false`）
3. 层级结构是否正确

### 问题 4: 动画卡顿

**排查**:
1. 使用 Instruments Core Animation 录制
2. 检查 Color Offscreen-Rendered（过多离屏渲染）
3. 检查视图层级是否过深
