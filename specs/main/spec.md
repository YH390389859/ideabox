# 收藏日历应用 - 功能规范

**版本**: 1.0.0  
**创建日期**: 2025-10-01  
**最后更新**: 2025-10-01  
**状态**: 已实现

## 概览

收藏日历（IdeaBox）是一款基于 iOS 平台的日历收藏应用，允许用户在时间轴上记录和查看各种类型的收藏内容（网页链接、文本日记、语音日记等）。应用采用 SwiftUI 构建，提供流畅的用户体验和直观的界面设计。

### 项目背景

- **设计来源**: 基于 Figma 设计稿
- **目标平台**: iOS 15.0+
- **开发框架**: SwiftUI
- **架构模式**: MVVM

### 核心价值

1. **时间可视化**: 将收藏内容与时间关联，形成个人时间线
2. **多类型支持**: 支持网页链接、文本、语音等多种收藏类型
3. **直观导航**: 横向日历滚动 + 纵向时间轴滚动的双向导航
4. **智能布局**: 根据内容自动调整界面布局

### FR-006: 智能高度调整

**优先级**: P1 (重要)  
**状态**: ✅ 已实现

#### 描述
每个时间段的高度根据该时段内的事件数量自动调整，充分利用屏幕空间。

#### 验收标准
- [x] 没有事件的时段保持最小高度（60px）
- [x] 有事件的时段高度 = 事件数量 × 事件卡片高度 + 间距 + padding
- [x] 同一时段内多个事件垂直堆叠，间距8px
- [x] 时间标签与事件区域完美对齐
- [x] 高度变化流畅，无跳变

#### 技术要求
- 使用整体式结构（`TimeSlotRow`）确保对齐
- 每个事件卡片高度固定为 72px
- 事件间距 8px

## 数据模型

### DayItem (日期项)

```swift
struct DayItem: Identifiable, Equatable {
    let id: UUID
    let weekday: String      // 星期几（一、二、三...）
    let day: Int             // 日期数字
    let date: Date           // 完整日期对象
    let isToday: Bool        // 是否为今天
}
```

### EventItem (事件项)

```swift
enum EventType {
    case link          // 网页链接
    case textDiary     // 文本日记
    case voiceDiary    // 语音日记
}

struct EventItem: Identifiable {
    let id: UUID
    let type: EventType
    let time: String            // 时间字符串 "HH:mm"
    let title: String           // 标题
    let subtitle: String        // 副标题
    let backgroundColor: Color  // 背景色
    let borderColor: Color      // 边框色
    let accentColor: Color      // 强调色
    let logoColor: Color        // 图标背景色
}
```

## 边界条件

### EC-001: 日期范围边界
- 最早日期：当前日期 - 60天
- 最晚日期：当前日期 + 60天
- 超出范围：不显示

### EC-002: 同一时段多事件
- 无事件：显示空白占位，最小高度60px
- 1个事件：高度约92px
- 2个事件：高度约172px
- 3+个事件：按公式计算，无上限

### EC-003: 农历日期
- 当前为简化实现
- 未来需集成真实农历转换库

### EC-004: 空状态处理
- 选中日期无事件时显示空白时间轴
- 不显示"暂无数据"提示
