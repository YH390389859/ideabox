# Feature Specification: 日历布局优化

**Feature Branch**: `002-layout-optimization`

**Priority**: High  
**Type**: UI 改进

## 功能概述

### 背景与问题

当前周日历视图存在以下布局问题：

1. **顶部空白过大**: `.padding(.top, 54)` 导致日历顶部有大片空白区域
2. **左右边距不当**: `.padding(.horizontal, 12)` 导致日期显示区域较窄
3. **日期分布不均**: 使用固定的 `spacing: 8`，日期之间间距固定，无法根据屏幕宽度自适应

### 期望的改进

- ✅ 减少顶部空白，从 54 降低到 16，再降低到 8
- ✅ 减少整体高度，从 100 降低到 60（更紧凑）
- ✅ 适当增加左右边距，从 12 增加到 16
- ✅ 日期均匀分布，自动填充屏幕宽度

## 功能需求

### FR-001: 减少顶部空白
**描述**: 将日历顶部 padding 从 54 减少到 8（分两步：54→16→8）  
**验收标准**:
- 顶部空白大幅减少（85%）
- 日历与顶部内容距离适中

### FR-001.1: 减少整体高度
**描述**: 将日历整体高度从 100 降低到 60  
**验收标准**:
- 日历区域更加紧凑
- 为下方内容留出更多空间

### FR-002: 日期均匀分布
**描述**: 7个日期按钮在屏幕宽度上均匀分布  
**验收标准**:
- 每个日期按钮占据相等的水平空间
- 日期之间的间距自动调整
- 在不同屏幕尺寸下都能正确显示

### FR-003: 调整左右边距
**描述**: 将左右边距从 12 增加到 16  
**验收标准**:
- 日历左右两侧有适当的留白
- 整体视觉更加平衡

## 技术实施

### 代码变更

**文件**: `IdeaBox/Views/WeekCalendarView.swift`

#### 变更 1: 移除固定间距，改用均匀分布
```swift
// 之前
HStack(spacing: 8) {
    ForEach(week.days) { day in
        // ...
    }
}

// 之后
HStack(spacing: 0) {
    ForEach(week.days) { day in
        // ...
        .frame(maxWidth: .infinity) // 均匀分布
    }
}
```

#### 变更 2: 调整整体高度
```swift
// 之前
.frame(height: 100)

// 之后
.frame(height: 60)  // 减少 40%
```

#### 变更 3: 调整 padding 值
```swift
// 之前
.padding(.horizontal, 12)
.padding(.top, 54)
.padding(.bottom, 8)

// 第一次优化
.padding(.horizontal, 16)
.padding(.top, 16)
.padding(.bottom, 8)

// 最终优化
.padding(.horizontal, 16)
.padding(.top, 8)     // 进一步减少
.padding(.bottom, 8)
```

### 影响范围

- ✅ 不影响数据模型
- ✅ 不影响业务逻辑
