# IdeaBox · 日常织机

状态：开发前的确定性设计稿。`blueprint.svg` 是可编辑布局依据，`blueprint.png` 是同源预览。画板为 1500 × 1150 px，三屏各为 402 × 874 pt；构图中的日期与 5/8 完成数为示例，正式界面必须绑定当前模型，不增加新种子数据或覆盖旧记录。

预览采用 macOS 原生 NSImage SVG 渲染为 3000 × 2300 PNG，已人工检查完整三屏、底部导航、文字和材料边缘。重新生成时在项目根目录执行 `python3 design/loom-20260906/generate-blueprint.py`，再执行 `DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer xcrun swift design/loom-20260906/render-blueprint.swift`。Quick Look 会将该 SVG 裁为正方形，不作为此设计板的导出方式。

## 核心语言

习惯是经线，每天的行动是纬线，完成是一个明确的织结；灵感是抽得出来的纸带、磁带和薄片。内容结构、打卡反馈、收藏材质和创建动作共享这个隐喻。主要页面仍叫「今天 / 习惯 / 收集」，文案不要求用户先理解隐喻才能使用。

不使用圆角卡片仪表盘、彩色统计方块、悬浮胶囊导航、星球花园、等级积分。主视觉由实际习惯和记录构成，不能以装饰图替代全部真实操作。

## Token 与公共尺寸

| Token | 值 | 用途 |
|---|---|---|
| paper | `#F3F0E8` | 页面、导航、线结镂空 |
| ink | `#202A2B` | 正文、导航、梭形按钮 |
| cobalt | `#3555E8` | 已完成经线、语音材料 |

- 页面左右边距 24 pt；内容宽为 `screenWidth - 48`。402 屏对应 354 pt。
- 系统中文字体，34 pt 半粗主标题，19 pt 半粗二级标题，15 pt 正文，12 pt 辅助；英文索引 8–10 pt 等宽。大日期 92 pt、Helvetica Neue 或系统紧凑数字字体。小英文仅补充识别，不能承载唯一信息。
- 所有交互命中区域至少 44 × 44 pt。小图标和标签可以在透明命中区内保持精细尺寸。
- 主要表面是平面薄材质。仅设备外观使用 43 pt 圆角；内容不继承设备圆角。
- 最下方导航视觉顶部为 y=778，主内容底部预留约 108 pt。正式实现按 safeAreaInsets 自适应，禁止硬写设备总高度。
- 导航三个文字标签的 x 为 24/94/164，基线 y=821；选中下划线 y=834、宽 30、厚 2 pt。标签各 62 × 50 pt 点击区域。
- 「拾起」按钮 bbox=(258,790,120,47)，轮廓为双尖梭形，按钮命中区域仍为完整 120 × 48 pt。图标为加号，正文清楚写「拾起」。不要把动画中的梭形路径当成唯一点击轮廓。
- 正文文字始终保持水平；材料可以有微小形变，不能牺牲阅读性。

## 01 今天：当前织面

以手机左上角为坐标原点，不含设计板偏移。状态栏区域约 0–56 pt。

| 元素 | 范围 / 基线 | 说明 |
|---|---|---|
| 页眉索引 | x24 / y76 | `TODAY / ON THE LOOM`，10 pt |
| 日期 | x20 / baseline159 | 大数字 92 pt；右侧月份和星期 |
| 当前完成数 | x245 / y126 | `5 / 8`，已完成数 32 pt 钴蓝 |
| 主标题 | x24 / baseline214 | 「今天，织一点。」34 pt |
| 副标题 | x25 / baseline242 | 「不必完美，每一根线都算数。」12 pt |
| 活织面 | x15–360 / y275–550 | 无容器、悬空；主体约 300 × 260 pt |
| 操作标签 | 阅读在右上、喝水在左中、锻炼在右下 | 细引线连接相应真实习惯，完成后显示明确勾选/状态 |
| 最近灵感标题 | x24 / baseline628 | 「灵感，先留一线。」19 pt |
| 灵感纸带 | bbox(24,648,354,86) | 打孔薄纸，极小角度；可点击阅读 |

织面不是新增业务对象。一个习惯对应一束经线，习惯 UUID 决定稳定颜色/横向顺序，不使用每次刷新变化的随机颜色。最近 7 天的完成记录决定横向交织密度、节点与色彩；未完成使用较浅的开放经线，不画破洞、不作惩罚性暗示。

可实现的曲面为归一化参数网格 u/v ∈ [0,1]，将经线和纬线投到一个略有扭转的二维曲面。参考 SVG 的 `surface(u,v)`。正式 Canvas 可将 60–100 根经线与 50–90 根纬线按设备性能调整密度；颜色明暗而不是重模糊承担织物深度。现有数据很少时仍应保留细线结构，但不能伪造完成状态。

标签只提取最多三个今天计划中的习惯。其余习惯通过显式「全部习惯」入口到矩阵；已全部完成时文案为「今天的线，已经织好。」并保留查看/撤销途径。不允许以不可见 Canvas 点击区域替代按钮。

点击纸带打开现有记录详情；「灵感」右侧箭头进入收集。无记录时纸带显示「把此刻的一点念头，留在这里。」和可见的「写一条」。日期或进度可进入实际统计/历史，不展示虚构计数。

| 元素 | 范围 / 基线 | 说明 |
|---|---|---|

| 周范围 | x24 / y195 | 日期范围按真实周生成 |
| 前/后周按钮 | x294–330 / x336–378 / y165–209 | 显示细箭头，命中 44 pt；未来不可进入 |
| 固定习惯列 | x24–120 | 宽 96 pt，包括名称、频率、编辑菜单 |
| 横向时间区 | x120–378 | 宽 258 pt，每日 44 pt，7 日内容宽 308 pt |
| 周标题行 | y227–289 | 星期和日期；当天墨色圆标 |
| 习惯行 | first center326 / rowHeight69 | 五行示例；真实列表纵向滚动 |
| 滑动提示 | x24 / y675 | 「左右滑动时间 · 点线结打卡」 |
| 新建按钮 | x24 / y713 | 「添加一根线」，44 pt 命中高度 |

默认滚到当天所在的最后一列，显示前方部分日期，不能压缩 44 pt 格宽挤进七天。375 屏固定标签列可保持 96 pt，时间 viewport 为 231 pt，可见约 5.25 天。更大 Dynamic Type 时习惯标签可增至 112–128 pt、行高增长，时间区仍可横滑。

- 每个交点是真正的 Button。完成=实色织结＋勾；未完成=空环；非计划日=短横线并明确无障碍标签「未安排」。是否允许历史补签服从现有模型能力，未来日期不允许打卡。
- 已完成当日可点击撤销；撤销动效是结轻轻松开。不要靠颜色区分状态。
- 标签点按或可见的「⋮」打开编辑表单。删除在表单/菜单中可发现，并确认。长按可以作快捷入口，不能作为唯一入口。
- 习惯名称最多两行。副标题只显示模型真实的计划频率，例如「每天」「周一 / 三 / 日」，不引入提醒时间、目标分钟数或通知功能的暗示。频率保持说明性中文，不将英文索引当正文。列表内容继续向下滚动，可固定或吸顶列头，确保横纵滚动互不抢手势。
- 无习惯时呈现三根松弛经线和「先添一根线。」＋新建按钮，绝不展示假完成格。

| 标签筛选 | x326 / y246 | 可见下拉入口，点击至少 44 pt |

| 文字纸 | bbox(24,308,354,163) | 黄绿打孔薄纸，标题/摘录水平 |

| 链接折页 | bbox(24,640,354,112) | 奶白，来源、题名、外链箭头 |

这些是记录的材料表面，不是统计卡片。不要统一套圆角、阴影、描边；纸用孔与边缘，磁带用穿孔与抽象织纹，链接用折角和来源区分。列表仍按日期分组、纵向滚动，标题/时间/标签保持稳定位置，便于扫视。模型没有保存音频波形采样，已保存录音只显示抽象等高刻纹，不伪造声音起伏。设计图中 `00:42` 和播放按钮仅用于展示有真实音频文件的记录状态。旧录音样例若没有文件，写明「仅文字备忘」，不得出现可用播放按钮或假时长。

整条材料点击进入现有详情/编辑，右侧或底部保留可见操作菜单。语音播放按钮是独立控件，不能同时触发详情；语音之间互斥，开始录音前停止播放。链接整条进详情，外链箭头可单独打开验证过的 URL。

搜索匹配现有标题/正文/URL/标签；空结果显示实际关键词、「没有找到这根线索。」及清除筛选按钮。类型与标签状态同时可见，不在退出页面后保留键盘焦点。

## 拾起、编辑与状态

「拾起」打开一张从下方展开的纸面，顶部标题为「这一刻，留下什么？」下方是三条全宽入口：写下来 / 录一段 / 留链接，再一条次级入口添加习惯。每行有清楚的文字与符号，不使用只靠形状理解的交互。进入编辑后使用稳定平面布局，字段、保存与取消维持可发现性；丰富文本和现有标签/心情/频率能力照常保留。

录音主区域采用实时波形磁带：录制、暂停、停止、预听、保存状态明确。用户看见的是 AVAudioRecorder 的音量数据，不能用循环的假波形冒充录音。拒绝麦克风权限时显示具体原因与设置入口；取消后清理未保存文件。背景中断、停止与权限回调沿用已有防护。

持久化错误显示在内容区顶部的一条朱砂色细边「存储状态」纸签，写出简短真实错误和可操作的重试/查看恢复文件入口。不能用模糊 toast 冒充保存成功。恢复文件仅在模型确有备份时出现。普通保存成功通过细微落线和轻触感反馈，不弹确认对话框。删除操作保留确认，避免误触。

## 动效节奏

| 行为 | 表现 | 时长 |
|---|---|---|
| 开屏 | 暖纸上的松线聚拢，一次梭子穿行，织成品牌记号，再成为首页织面的第一束线 | 约 2.2–2.6 s，可跳过 |
| 首页静态呼吸 | 曲面控制点仅 ±1–2 pt 变化，细线张力轻动，标签固定 | 7–9 s 周期 |
| 打卡 | 对应经线拉紧，纬线穿过并落结，完成勾随后稳定 | 420–560 ms |
| 撤销 | 织结放松、露回空环 | 260–320 ms |
| 页面切换 | 标题与线条短距离滑入，选中下划线移动 | 200–260 ms |
| 打开材料 | 被选材料平整展开为阅读纸面；正文持续水平 | 320–420 ms |
| 保存 | 纸边/磁带收束成一根线，进入索引；不播放全屏庆祝 | 400–500 ms |

循环动效只在当前可见页且 scenePhase active 时运行；降低动态效果时禁用曲面循环、穿针和飞行，改为不超过 120 ms 的交叉渐隐，状态即时可读。动画中断时允许直接到达最终状态。不要拖延保存或使用固定延时承担业务正确性。

## 实现与验收边界

1. 不变更数据 schema，不清空本地 JSON，不替换用户的习惯与记录；设计图中的文案只是示例。
2. 首先原生构建三屏、创建/编辑流程和底部导航；首页织面由 Canvas 绘制，点击点与可访问标签由 SwiftUI 叠层承担。
3. 保留现有真实录音、富文本、搜索、筛选、计划频率、历史、删除和恢复能力。
4. 402 pt 与 375 pt 上核验日期字形、导航宽度、矩阵点击尺寸、键盘、安全区与滚动；更大字体不能让正文被材料边缘裁切。
5. 使用实际 App 截图与短录屏交付，清楚区别艺术概念图、精确布局稿和已实现界面。
