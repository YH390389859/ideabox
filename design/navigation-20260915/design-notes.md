# 日常织机：记录入口重新设计

用户反馈：首页底部「说一点」左边的加号和主入口争抢注意力，无法从符号判断两者的区别。

这次调整以一个清楚的记录入口建立层级；手动记录在对话输入区域直接可见，保留不用 AI 的完整记录路径。

## 已交付设计

- `blueprint.png`：3000 × 2340 像素，三屏总览。
- `blueprint.svg`：1500 × 1170 画布，原生可编辑矢量稿。
- `generate-blueprint.py` 与 `render-blueprint.swift`：可重建设计图片。

## 交互层级

1. 首页导航栏只有三个浏览目的地「今天 / 习惯 / 收集」和一个「说一点」梭形主入口。删除相邻的加号，不留下空占位。
2. 「说一点」保持既有对话流程；输入框下方，左侧显示轻量连接状态，右侧显示「自己记 ↗」。这是有文字说明的次级操作，并提供至少 44 pt 的触控区域。
3. 点击「自己记」打开原生 sheet，提供「写下来 / 录一段 / 留链接 / 添加习惯」。未配置 API Key、离线时同样可以访问。
4. 手动记录的编辑表单、持久化与录音能力继续复用项目现有实现。

## 布局依据

- 稿件设备内容尺寸为 402 × 874 pt。
- 首页导航保留 24 pt 左右页边距，三个文字标签均匀展开；右侧主入口宽 108 pt，箭头与文字作为一个完整按钮。
- 对话页输入框下的「自己记」不使用浮动按钮或额外加号；字体为 13 pt 并随系统动态字体缩放，触控区域至少 44 pt；墨色与流式连接状态形成轻重差异。
- 手动 sheet 使用大字标题、四张有材料色差的横向选项，不引入新的重复导航层。
- 小屏时，导航优先保证标签、44 pt 触控面积和主入口宽度；手动 sheet 内容可滚动。

## 动效

沿用原有轻柔按压反馈和系统 sheet 过渡；避免记录入口同时出现多个持续运动的焦点。开启减弱动态效果时保持静态状态指示和标准可访问交互。

## 设计验证

使用 AppKit 原生 SVG 渲染生成 PNG 并查看整张图片，确认 CJK 字体正确、各屏无文字溢出、首页没有残留加号、对话入口和手动路径均清楚可见。此目录内不包含 App 功能改动。
