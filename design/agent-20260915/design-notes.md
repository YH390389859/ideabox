# 日常织机 · 对话式 Agent

先完成三屏高保真设计图，再开发原生界面与真实工具执行。`blueprint.svg` 为可编辑设计源，`blueprint.png` 为 3000 × 2340 展示图。设计沿用项目暖纸、钴蓝线束、酸绿梭子与黏土色辅线；没有使用虚构截图或外部图片资产。

## 一句话成为材料

入口命名「说一点，织进去。」。它延续日常织机的材料语言：原话是纸条，习惯操作是酸绿打孔回执，日记是折页。页面不采用连续聊天气泡，内容和实际动作组成一段可读的编织时间线。状态清楚区分等待输入、正在理解、正在保存、保存成功与失败；设计中的成功回执仅可在本地保存成功后出现。

首屏的蓝色线束形成松弛立体环，黏土色线穿过环，酸绿梭子停在交点。慢速呼吸和轻微相位流动表达待机；输入时线条逐渐收拢，发送时梭子沿曲线滑出，回执出现时蓝色细线连接操作。避免持续大幅位移、弹跳与强烈光效。减少动态效果时固定线束并以淡入替代路径运动；页面不活跃时停止动画。

## 三个页面

1. **对话采集。** 顶部返回与设置，双行大标题，精细线束，两个启发式输入建议，底部固定输入栏及梭子发送按钮。键盘出现时收起大幅线束和建议，将空间交给文字。
2. **操作回执。** 原始文字完整保留；模型提出结构化动作，App 验证和执行后形成真实回执。每个回执提供查看与撤回；撤回状态需明确可见，同一工具调用不能重复写入。示例同时完成阅读习惯与保存日记，日记只使用用户原话，不推断心情。
3. **DeepSeek 设置。** 自带 API Key，Keychain 储存，默认遮盖，可显示/隐藏；模型名称是可编辑字段。保存与测试需展示实际结果，未连接状态不能表现为成功。设置页直接说明发送到 DeepSeek 的对话和必要上下文。

实现更新：上图保留初版设置页设计。API Key 已根据后续反馈改为普通文本输入框，默认显示并支持系统输入、选择和粘贴；实际界面与说明见 [Agent 使用文档](../../docs/agent.md)。

## 原生开发约束

- 页面左右留白 24 pt，基础参考设备 402 × 874 pt；可点击区域至少 44 pt，实际图标可更小。
- 正文与收据自适应动态字体；输入、结果列表支持键盘和紧凑屏幕。
- 界面上的模型名称是配置示例，实际默认值需按 DeepSeek 当前官方模型确认。
- 对话文字使用 SSE 流式展示，工具参数需要累计完整后再验证执行。不能用收到的部分参数更新业务数据。
- 实际功能文案遵循能力边界：链接收藏不自动宣称抓取网页；没有量化习惯时不把「喝了两杯水」推断为完成目标。
