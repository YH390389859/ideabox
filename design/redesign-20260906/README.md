# IdeaBox · 暖白精致

## 产品范围
原生 iPhone 应用，支持今天总览、习惯创建/编辑/打卡、文字日记、语音录制与播放、链接收藏、搜索和标签筛选。本地保存，首次提供示例内容；不依赖账户或云服务。

## 视觉
暖白 #F7F6F2，墨色 #282735，淡紫 #EBE9F9，主色 #7770DD，鼠尾草绿 #DDE9DE，杏色 #F1DFD1。24 pt 页边距，24–30 pt 卡片圆角，细边框、轻阴影；系统中文字体，英文小标题适度字距。清楚区分可点击控件和内容。

## 三个页面
- 今天：日期、问候、进度与生长意象、今日习惯、最近收集。
- 习惯：周历、完成进度、习惯列表、新建与编辑、历史补签；按设定频率显示。
- 收集：关键词搜索、类型和标签过滤、时间线卡片、编辑/删除、文字/录音/链接创建。

## 动效
页面淡入与短距离位移约 240 ms；标签选择胶囊用 matchedGeometryEffect；打卡用约 350 ms 弹簧缩放与触感；进度平滑变化；首页生长意象缓慢漂浮。尊重系统“减少动态效果”，非当前页停止持续动画。录音波形来自实时音量，避免模拟录音。

## 验证
以实际模拟器截图为交付依据，核对 375 pt 与 402 pt 宽度。本地数据使用独立存储路径测试，确保重启保留记录。
